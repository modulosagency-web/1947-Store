GitHub Token Setup (One-Time Setup)

This token is saved only in your browser and is never sent to any server. You only need to set it up once. After that, you can upload products anytime.

Complete Guide: How to Get Your GitHub Token

Follow these steps carefully to generate a personal access token. This token allows the admin panel to upload products and images directly to your GitHub repository. Do not share this token with anyone.

1

Log in to GitHub

Open github.com/login and sign in with the GitHub account that owns the 1947-Store repository.

2

Open Developer Settings

Click your profile picture (top-right) → Settings → scroll down to the bottom of the left sidebar → Developer settings.

Or open this direct link: github.com/settings/tokens

3

Generate a New Token

Click "Generate new token" → choose "Generate new token (fine-grained)".

Use Fine-grained tokens — they are more secure than classic tokens.
4

Fill in Token Details

Token name: 1947-Admin-Panel

Expiration: Choose 90 days or No expiration (your choice)

Description: Token for admin panel to upload products

5

Select Repository Access

Under Repository access, choose "Only select repositories".

Then select 1947-Store from the dropdown list.

6

Set Permissions

Under Permissions → Repository permissions, find Contents and set it to "Read and write".

Important: Without "Contents: Read and write" permission, the admin panel cannot upload images or update products.
7

Generate the Token

Scroll down and click the green "Generate token" button.

8

Copy Your Token

A token starting with github_pat_ will appear at the top. Click "Copy" to copy it.

Copy it now! GitHub only shows this token once. If you close the page without copying, you'll need to generate a new one.
9

Paste the Token Below

Come back to this page and paste the token in the input field below. Click "Save Token" — it will be stored securely in your browser only.

Security Notes:
• Your token is stored only in your browser's local storage.
• It is never transmitted to any server other than GitHub's API.
• If you ever suspect your token is compromised, revoke it immediately at github.com/settings/tokens and generate a new one.
• Never share your token with anyone, including in screenshots or messages.
